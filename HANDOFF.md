# Halden Atelier — handoff package

1. Put these files in an empty project folder (keep the structure).
2. Open a terminal in that folder and start Claude Code.
3. Paste the prompt in KICKOFF_PROMPT.md.
4. Approve the plan, then go phase by phase (docs/IMPLEMENTATION_PLAN.md).

Contents: CLAUDE.md (auto-read project memory) · docs/ (PRD, design system, 3D pipeline, plan) · data/options.json (all options, prices, regions, rules) · reference/prototype.html (working prototype) · reference/paint-shader.js (shader to port).
